    Help

    Navigation Tagger turns your nav content sheet into tagged links. Paste the sheet, review the links, then copy the tagged output for Wrike (or download it as CSV / XLSX).

    Quick start

    1. Paste. Copy the cells from Excel or Google Sheets into the box. Links generate on paste. You can also click Generate or press Ctrl+Enter.
    2. Review. Fix missing URLs, confirm guessed fields, reorder links and add the nav asset.
    3. Export. Click Copy N links for Wrike and paste into Wrike.

    No sheet handy? Click Load sample data.

    What your sheet should look like

    TOPS                                  nav name (ALL CAPS)
FEATURED                              section name
Link          URL                Start     End   Owner
New Arrivals  /tops/new-arrivals/
Holiday Tops  /tops/holiday/     11/20/26        Alex
    • The header row must contain a cell that says URL. The label is in the column to its left.
    • Nav names are short, ALL CAPS, with no numbers or underscores. A file title like HOLIDAY TWO 2026_CONTENT PLAN MASTER is ignored.
    • A section can have several Link / URL column pairs side by side. A blank row ends a block.
    • "Site Merch Updates" sheets also work. DESKTOP rows become links. APP rows are not output, but a matching tag ID becomes the link's data-category_name. If the sheet has no nav headings, the nav is guessed from the URLs. Rename it in Show details.

    Review

    Status line. "N missing URLs · Next" jumps to the next link with no URL. "N to confirm" lists fields the tool guessed; Confirm all accepts them. "N rows skipped" counts rows with no URL.

    Show details. Check how each nav section is tagged:

    • Menu / Section: click the menu name to rename it everywhere.
    • promo_id: the group name in analytics.
    • promo_position: where the link sits in the nav.
    • name prefix: added to the front of every promo_name in the section.

    Dashed blue fields were guessed. Check them. Editing a field confirms it.

    Menu tabs filter the list by nav. A red dot means that nav has missing URLs.

    Link cards:

    • Checkbox: include or exclude the link.
    • NEW switch: adds " NEW" to the name in the Wrike output.
    • ☰ handle: drag to reorder, or move into another column of the same nav (not across navs).
    • ▸ arrow: opens the card to edit the URL, use Move up / Move down, and edit the tags (data-category_name and promo_name). Press Enter or click away to apply a URL.

    Tagged link format:

    /path/?promo_id=<id>&promo_name=<name>&promo_creative=TextOnly&promo_position=<position>

    Asset panel (right of each nav) is for the dropdown banner. Enter an Image (CDN link or file name) and a Destination link. promo_creative is the image file name without host, query or extension. promo_position defaults to Dropdown_<Nav>_Banner. The asset appears in the Wrike output only.

    Options. Full URLs adds the torrid.com domain. Hide redirects / ended hides flagged links from the list and from exports.

    Export

    Copy for Wrike copies one table per navigation with formatting. Untick a navigation under "Wrike navigations to include" to leave it out. Use Show Wrike preview to see what will be copied.

    The arrow beside it offers:

    • Copy table (TSV): one row per link, for Excel / Sheets.
    • Copy URLs only: tagged URLs, one per line (skips links with no URL).
    • Download CSV / XLSX: the XLSX is laid out like the content sheet, with missing URLs shaded red.

    The table, URL, CSV and XLSX options follow the current menu tab. Choose All to export every nav. The Wrike copy follows the navigation checkboxes instead.

    Saving your work

    • Autosave: your work saves in this browser only (see "Saved" at the top).
    • Project ▾ → Save to file downloads a .json backup you can share. Load from file reopens it.
    • Undo: clearing, regenerating and loading sample data show an Undo button for about 8 seconds.

    Regenerating resets your edits (URLs, order, assets). Use Undo to bring them back.

    Troubleshooting

    "No link blocks detected"The header row with the URL cell wasn't copied. Re-copy including it.
    Nav is named "MERCH" or wrongThe sheet has no nav headings. Rename it in Show details.
    Wrong promo_positionIt was guessed. Edit it in Show details.
    A link is missing from an exportIt may be unticked, hidden by Hide redirects / ended, or on a different tab.
    Formatting lost in WrikeUse Copy for Wrike, not Copy table.
    "XLSX library failed to load"Check your internet connection and reload.
    Status shows "Not saved"Browser storage is blocked or full. Use Project → Save to file.
